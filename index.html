Les 3 règles du parcours
  • Une séance = une action cochée. 30–45 min, pas plus. Trois soirs par semaine.
  • Chaque séance finit par un git commit sur ton dépôt GitHub. Le code vit en ligne, pas sur ton PC.
  • Chaque phase finit par un livrable montré à quelqu'un (tes potes, ton père, ton tuteur). C'est ça qui débloque les badges dorés.
